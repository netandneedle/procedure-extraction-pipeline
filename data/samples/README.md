# Sample source

`aa23-061a-stopransomware-royal-ransomware.pdf` is CISA Cybersecurity Advisory
AA23-061A, "#StopRansomware: Royal Ransomware" (March 2023), downloaded from
https://www.cisa.gov/sites/default/files/2023-03/aa23-061a-stopransomware-royal-ransomware.pdf

It is a work of the United States Government and is in the public domain.
It is included so the Quick Start ends in a real bundle: the advisory
describes a full intrusion in order, which exercises chunking, sequencing,
and technique mapping. Mark it as sequential when you add it; the
auto-detector leans towards "not sequential" when unsure, and an advisory's
mixed structure (narrative, indicator tables, mitigations) can tip it.

Vendor threat reports are not included; bring your own.
